# Project 01 - Database Creation

## Overview

This project demonstrates the basic SQL Data Definition Language (DDL) commands used to create a relational database and table.

## Objectives

- Create a database named **PEOPLE**
- Create a table named **TBLpeople**
- Define appropriate data types
- Insert sample records into the table

## SQL Concepts Used

- CREATE DATABASE
- USE
- CREATE TABLE
- PRIMARY KEY
- VARCHAR
- INT
- INSERT INTO

| File | Description |
|------|-------------|
| create_database.sql | SQL script that creates the database, table, and inserts sample data |
